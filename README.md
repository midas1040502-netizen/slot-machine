# 🎰 水果拉霸 Fruit Slot Machine

單檔 HTML 拉霸遊戲——無任何外部依載、無需建置，用瀏覽器打開就能玩。

## 🎮 玩法

- 3 個轉輪，對齊**中間金色中獎線**即中獎（經典單線制，上下兩列為裝飾）
- 拉霸桿動畫 + 三輪錯峰停止 + Web Audio 合成音效（可靜音）
- **空白鍵**快速轉動、**自動轉**連續開轉
- 版面會依視窗大小自動縮放，手機也看得見按得到 SPIN

## 🏆 獎項（四階制）

| 獎項 | 中獎組合 | 機率 |
|------|---------|------|
| 🎰 頭獎 | 7️⃣ 7️⃣ 7️⃣ | 5% |
| 💎 二獎 | 💎 💎 💎 | 10% |
| 🎊 三獎 | 任意三個相同水果 | 20% |
| 🍀 四獎 | 三個同顏色水果 | 30% |
| — | 未中獎 | 35% |

- 水果共 7 種：🍎 🍌 🥝 🍒 🍋 🍉 🍇
- 同色分組：紅＝🍎🍒🍉、黃＝🍌🍋、綠＝🥝、紫＝🍇
- 頭獎觸發彩帶 + 機台震動 + 大獎音樂

## 📊 記分板

- **中獎次數**：每中一個獎（頭/二/三/四獎）累計 +1，重整不遺失
- **上次獎項**：顯示最近一次中的獎名
